# Logo sources

Works with page (`/works-with`) + homepage band. One entry per client. Not prose — URL, fetched date, license/brand-page note as stated on the source. Fetched 2026-09-06.

Nine clients below shipped as a normalized official SVG mark (single `fill="currentColor"`, viewBox preserved, no raster, no script, `<title>` set to the exact matrix spelling). The remaining ten render as a text wordmark in the shared Archivo type per the AD build sheet's explicit fallback (`AD-CLIENTS-VISUAL-SHEET-2026-09-06.md` §4: "If a mark cannot be sourced as an official SVG... render the client's wordmark as text in the shared type and report it — never fabricate a logo"). Tyler's logo ruling (addendum, same sheet) removed the GOV-2 legal-clearance gate on shipping a sourced mark; it did not supply marks for clients nobody had sourced yet, so the ones below with no verified official-brand source stay text this pass.
